# JavaScript - DOM Manipulation

## Description
This project covers basic to advanced concepts of JavaScript DOM (Document Object Model) manipulation, event handling, and making network requests using `XMLHttpRequest` and the `Fetch API`.

## Learning Objectives
By the end of this project, you should be able to explain:
- How to select HTML elements using JavaScript
- Differences between ID, class, and tag name selectors
- How to modify HTML element styles
- How to get and update HTML element content
- How to modify the DOM structure dynamically
- How to make HTTP requests using `XMLHttpRequest` and `Fetch API`
- How to listen and bind to DOM and user events

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`, `vscode`
- All files will be interpreted on Chrome browser (version 57.0 or later)
- All files must end with a new line
- Code must be `semistandard` compliant
- The `var` keyword is not allowed (use `const` or `let`)
- HTML pages must not reload on actions
